# Polices

Ce dossier doit contenir les fichiers `.ttf` réels des polices déclarées dans
`utils/fonts.ts` et chargées dans `app/_layout.tsx` :

- NotoSansJP-Regular.ttf
- NotoSerifJP-Regular.ttf
- YuGothic-Regular.ttf

Je n'ai pas pu inclure les fichiers binaires eux-mêmes (pas d'accès réseau
depuis cet environnement). Télécharge-les (ex: Google Fonts pour Noto) et
dépose-les ici avec exactement ces noms — rien d'autre à changer.
